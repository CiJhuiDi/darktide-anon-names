# 匿名名池 (Anon Names) v1.0.3

《战锤 40K：暗潮》DMF mod：**AnonPlayers 的附属** —— 不改它「谁该被匿名」的决定，只把它的掩码（`???` / 随机代码 / 性格名）换成中文意象化名。

适合直播：观众看到的不再是雷同的 `???` 或 `8f0ea` 这种代码，而是一池认得出的中文名字。

## 功能

- **化名风格随时切换**（共 9 个池、421 项）：
  - 二十四节气 24 项（立春 … 大寒）
  - 花草五大类**各自独立可选用**：花木 57 / 草本 38 / 藤蔓 30 / 树木 40 / 园艺花卉 43
  - 全部花草 208 项
  - 中国传统星名 189 项（二十八宿距星、北斗七星、著名亮星、三垣与二十八宿星官、近南极星官）
  - 全部混合 421 项
- **同一玩家全程同名**：按账号 / 角色 ID 做稳定哈希，跨局也是同一个化名
- **机器人可单独设置**：也用化名 / 保持 `???` / 显示游戏原名
- 生效位置：社交面板、聊天、结算、头顶名牌、哀星号队伍面板、邀请组队界面、预任务大厅与角色选择
- 与 [color_mark](https://github.com/CiJhuiDi/darktide-color-mark) 共存：被 `/mark` 的玩家仍优先显示彩色真名

## 依赖

- **DMF**（Darktide Mod Framework）
- **AnonPlayers**（**必需**）—— 本 mod 只替换它的掩码，不自己做「谁该被匿名」的决策

## 安装

1. 把 `anon_names` 文件夹整个复制到游戏 mods 目录：
   `Steam\steamapps\common\Warhammer 40,000 DARKTIDE\mods\`
2. **不需要**改 `mod_load_order.txt`：DML 会加载 mods 目录下所有 mod，而本 mod 与 AnonPlayers 的加载顺序无关（它包的是函数而不是 CLASS 钩子）
3. 启动游戏 → ESC → **Mod Options → 匿名名池** 调整风格
4. ⚠️ 装好后**完全重启游戏**才生效（热重载只部分加载新代码，日志会新旧混）

## 配置项

| 设置 | 默认 | 说明 |
|---|---|---|
| 化名风格 `mask_style` | 二十四节气 | `jieqi` / `flora` / `flower` / `herb` / `vine` / `tree` / `garden` / `star` / `mixed` / `off` |
| 机器人 `bot_handling` | 开（也用化名） | `开` 机器人也用化名 / `关` 保持 AnonPlayers 的 `???` / `显示游戏原名` |

**账号名不设开关**：账号名要不要匿名完全由 AnonPlayers 的「其他账户名称 / 你的账户名称」决定，本 mod 只跟随——它匿名就换化名，它放行就放行。

## 字形限制（重要）

游戏的中文字体是 Noto Sans SC 的**游戏子集**，覆盖范围约等于 **GB2312 一级字库（3755 个常用字）**。二级字（次常用字）及更生僻的字会渲染成方块。

踩过的坑：距星名「氐宿一 / 昴宿一 / 觜宿一 / 轸宿一」的第一个字正好都是二级字，在头顶名牌上显示成「□宿一」。

所以池子**只收录一级字**，因而损失了一些本来很好的名字（茉莉、蔷薇、薰衣草、栀子、白桦、楠木、天璇、天玑…）。想往池子里加名字，请先按一级字库校验，别只看「能不能用 GB2312 编码」。

## 关于撞名

化名由稳定哈希直接从池子里取，**刻意不做去重**：同队两人有概率拿到同一个化名，池子越小概率越高。这样换来的是零状态设计——不存在「池子耗尽」「集体重排」「局内换名」这些问题。

想少撞名就换大池子，而不是期待去重：

| 池 | 4 人队撞名率 |
|---|---|
| 二十四节气 | ~23% |
| 藤蔓 | ~19% |
| 园艺花卉 | ~14% |
| 草本 | ~16% |
| 树木 | ~15% |
| 花木 | ~10% |
| 传统星名 | ~3.2% |
| 全部花草 | ~2.9% |
| 全部混合 | ~1.4% |

## 已知限制

- **依赖 AnonPlayers**：未安装或版本不可 hook 时本 mod 静默不生效，日志会打印 `[anon_names]` 开头的警告
- **账号名**：AnonPlayers 只管 `user_display_name`，**没有覆盖 presence 的 `account_name()`**（实测那条会返回 `名字#1234` 真名）。本 mod 从 v1.0.3 起补了这层兜底：别人的账号名跟随「其他账户名称」设置，你自己的账号名跟随「你的账户名称」
- **「我的角色」集合**：本 mod 会缓存 `data_service.profiles:fetch_all_profiles()` 返回的**本账号全部角色**，判据因此是确定性的 —— 在集合里 = 你（含角色选择界面里未选中的其他角色），有 `character_id` 但不在集合里 = **别人**
- **判定不了就不动**：只在**确证是别人**时才覆盖上游放行的真名；拿不到本机档案或 profile 缺 id 时一律放行 —— 宁可少藏一层，也不能把玩家**自己**的名字改掉（v1.0.1 就踩过这个坑：判定不了被当成「不是我」，把自己的名字也匿名了）
- **v1.0.1 / v1.0.2 修掉的泄漏**：AnonPlayers 的 `is_me` 判据是 `view_active("main_menu_view") or ...` 的**短路**，主菜单一激活就把所有玩家当成「我」，于是用「我自己」那两个「不匿名」的设置去裁决别人 → 主菜单的社交 / 最近玩家列表里显示真名。本 mod 现在会甄别「上游真的决定放行」和「上游被短路骗了」，只对前者照抄真名
- **profile 数据残缺时可能显示 `???`**：上游拿不到 profile（无 character_id / account_id）且原函数返回 nil 时，本 mod 没有稳定 key 可用，只能保持上游的 `???`（不会泄漏真名）
- 任务中（combat）头顶名字仍由 AnonPlayers 处理，本 mod 跟随它的结果
- `mask_style` 若存着已删除的旧值，按「关闭」处理（不会报错也不会乱改名）
- 池子里有 8 个 4 字名和 1 个 5 字名，极窄的名牌可能显示不全
